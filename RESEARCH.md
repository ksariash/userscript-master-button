# Official research — 2026-10-13

Current documentation was inspected before selecting the probe dependencies. Sources describe capabilities; they do not establish behavior on the user's device.

| Primary source | Finding and consequence |
| --- | --- |
| [Defuddle README](https://github.com/kepano/defuddle) and [package manifest](https://github.com/kepano/defuddle/blob/main/package.json) | 0.19.5, MIT; browser core and Node DOM entry points. Async extraction can request remote content. Disable `useAsync`, extract on a clone, and preserve the inventory. Actual fixture extraction removed legitimate prose in a mixed container; absence is never a delete decision. |
| [Userscripts release docs](https://github.com/quoid/userscripts/tree/release/4.x.x#api), [development docs](https://github.com/quoid/userscripts), [App Store release notes](https://apps.apple.com/us/app/userscripts/id1463298887) | Asynchronous granted GM storage/requests require content scope. Documented request types and abort behavior need version matching. Safari CSP may still block code. Version/update metadata is supported; the cited iOS 1.8.6 notes say automatic update checks were temporarily disabled. Confirm the actual installed version instead of assuming automatic checks. |
| [Transformers.js](https://github.com/huggingface/transformers.js), [WebGPU guide](https://huggingface.co/docs/transformers.js/guides/webgpu), [pipeline API](https://huggingface.co/docs/transformers.js/api/pipelines) | Pin 4.3.1 for the experiment. Real local inference via ONNX; CPU/WASM and WebGPU are distinct backends. Quantization reduces weight cost. Node CPU execution does not validate browser WASM or Safari WebGPU. |
| [ONNX Web deployment](https://onnxruntime.ai/docs/tutorials/web/deploy.html) | Matching JS/WASM artifacts, appropriate worker paths, and a secure context matter. CSP support requires suitable asset serving; a userscript cannot simply assume all page policies are compatible. Pinned transitive web runtime is 1.31.0-dev.20260914-8d85527a0; native Node runtime is 1.30.0. A release should consider a matched stable browser stack after the compatibility probe. |
| [Google FLAN-T5-small model card](https://huggingface.co/google/flan-t5-small), [ONNX conversion](https://huggingface.co/Xenova/flan-t5-small) | Apache 2.0 language model, instruction-tuned sequence-to-sequence generation; conversion is a separate maintained checkpoint. Pin revision `311454e83bc784267fd7eef5940ee854144abbec`. No application accuracy follows from the model card. This probe only evaluates English. |
| [SmolLM2 official card](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct), [ONNX conversion](https://huggingface.co/onnx-community/SmolLM2-135M-Instruct-ONNX) | Apache 2.0 compact instruction model. Conversion revision `b8a5c0f183b78c55955a5364f610c36668b5e681`; q4 weight file 180,581,125 bytes from repository metadata. Researched alternative, not a measured capability or selected model. |
| [WebKit Safari 26.0](https://webkit.org/blog/17333/webkit-features-in-safari-26-0/), [26.6](https://webkit.org/blog/18178/webkit-features-for-safari-26-6/) | Safari 26.0 ships WebGPU on iOS and other Apple platforms; 26.6 refines WASM streaming compilation. Neither proves userscript worker/CSP/cache behavior. |
| [Azure Speech REST](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech) | Region/resource-specific authorization, voice list, SSML, and selected output formats. A synthesis response is capped at ten minutes, so long documents need safe segmentation. REST audio is not word-boundary timing. No live Azure call was made. |
| [Obsidian Reader](https://obsidian.md/help/web-clipper/reader), [Highlighter](https://obsidian.md/help/web-clipper/highlight), [popup source](https://github.com/obsidianmd/obsidian-clipper/blob/main/src/popup.html) | Readable type/formatting, source metadata, typography options, and contextual actions on both views. Derive composition, not copied assets or native-extension dimensions. |
| [Readwise annotations](https://docs.readwise.io/reader/docs/faqs/highlights-tags-notes) | Source/reader annotations normally sync; matching can fail and should be reported. Derive local controls and graceful uncertainty. No signed-in product usability test was performed. |
| [Apple materials](https://developer.apple.com/design/human-interface-guidelines/materials), [toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars) | Restrained functional materials, deliberate actions, logical grouping, and legible content. Web CSS is not Apple's native material system. |

Dependency licenses and exact transitive versions are recorded in `package-lock.json`. The study uses Lucide 1.56.0 vector icons (ISC); the exact glyphs come from the library, not reference-product artwork.
