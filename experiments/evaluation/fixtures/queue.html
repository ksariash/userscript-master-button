Why the queue stopped twice

The queue appeared healthy until two workers finished at the same time. Each worker believed it had received the last available task.

const task = await queue.claim();
if (task) await processTask(task);

Claiming a task must be atomic. Otherwise a second worker can observe state that the first worker has already changed.
